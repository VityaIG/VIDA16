# VIDA16 (AIDA64 для iOS) — Мониторинг процессора, температуры и аккумулятора

**VIDA16** — аппаратный монитор для iPhone (аналог AIDA64 и CPU-Z для iOS), отображающий реальную ёмкость аккумулятора (mAh), температуру процессора (°C / °F), троттлинг, загрузку ядер Apple Silicon и использование оперативной памяти (RAM).

---

## ⚡ Основные возможности VIDA16

- **🔋 Аккумулятор в реальном времени:**
  - Настоящая паспортная емкость (Design Capacity) в **mAh** (например, 3 582 mAh для iPhone 16 Pro, 3 274 mAh для iPhone 15 Pro).
  - Текущий остаток емкости в **mAh** на основе уровня заряда.
  - Напряжение ячейки (Voltage, 3.7V - 4.35V).
  - Процент износа и состояние здоровья (Battery Health).
  - Статус зарядки и режим энергосбережения (Low Power Mode).

- **🔥 Температура и троттлинг процессора:**
  - Считывание системного состояния нагрева через `ProcessInfo.ThermalState` (норма, нагрев, троттлинг, критический).
  - Расчет расчетной температуры SoC в **°C** и **°F**.
  - Индикатор активации троттлинга CPU под высокой нагрузкой.

- **🚀 Архитектура SoC и загрузка ядер:**
  - Определение чипа: Apple A18 Pro, A18, A17 Pro, A16 Bionic и др.
  - Разделение на производительные (P-Cores) и энергоэффективные (E-Cores) ядра.
  - Число GPU ядер и производительность Neural Engine (TOPS).
  - Мониторинг загрузки каждого ядра в реальном времени.

- **💾 Оперативная память (RAM) и Накопитель:**
  - Точный разбор памяти через Darwin Mach Kernel API (`vm_statistics64`): Wired, Active, Inactive, Free.
  - Объем встроенного накопителя NAND Flash (занято / свободно в GB).

- **📱 Характеристики экрана:**
  - Физическое разрешение экрана и плотность пикселей (PPI).
  - Поддержка ProMotion 120 Гц.

## 🛠 Запуск в Xcode

```bash
open ios/App.xcodeproj
```
1. В **Signing & Capabilities** укажите свой Apple ID (Personal Team).
2. Выберите свой iPhone в списке устройств.
3. Нажмите `Cmd + R` для сборки и запуска на устройстве.
